Honesty note: Boundaries at every level are generated (Voronoi sub-division of a simplified state outline), not official. To keep the demo light, each district is split into a representative set of real block names, not all 385 blocks, and panchayats carry synthetic IDs (GP-01…) instead of real names. Production will use verified GFS forecasts, IMD / TNAU AWS and rain-gauge data, official Panchayat GIS boundaries (over 12,000 village panchayats) and DEM / land-cover data.
Illustrative prototype — no ML validation claimed. Production model: LightGBM + quantile regression on verified GFS, IMD / TNAU AWS and DEM data.
