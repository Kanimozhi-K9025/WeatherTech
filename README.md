WeatherTech

AI-Powered Panchayat-Level Weather Downscaling

Project Description

WeatherTech is a concept prototype that demonstrates how block-level weather forecasts can be converted into localized Panchayat-level weather information to support farmers and rural communities.

Features

- Interactive map with 12 illustrative Panchayat polygons.
- Coarse Forecast and Downscaled View toggle.
- Maximum and minimum temperature.
- Rainfall probability and P10–P90 uncertainty range.
- Confidence/support indicator.
- Agricultural advisories.

Technologies Used

- HTML
- CSS
- JavaScript
- SVG

Setup Instructions

Option 1: Download the repository and open "index.html" in a web browser.

Option 2: Run a local server:

python -m http.server 8000

Open "http://localhost:8000" in your browser.
